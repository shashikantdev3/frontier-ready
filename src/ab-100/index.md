## What the exam tests

These are Microsoft's official topic areas and weights in the skills outline that applies from **16 November 2026**.

| Topic area | Weight |
|---|---|
| Plan AI-powered business solutions | <span class="range" style="--lo:35;--hi:40">35–40%</span> |
| Design AI-powered business solutions | <span class="range" style="--lo:30;--hi:35">30–35%</span> |
| Deploy AI-powered business solutions | <span class="range" style="--lo:20;--hi:25">20–25%</span> |

{% note "If you sit before 16 November" %}
Microsoft says planning and design gain weight in the new outline and deployment loses some. The study guide does not publish the old percentages, so study all three areas either way.
{% endnote %}

{% more "See every skill in the outline" %}
**Plan.** Decide where agents help with automation, analytics and decisions. Check that grounding data is accurate, relevant, current, clean and available. Apply the AI adoption process from the Cloud Adoption Framework. Design multi-agent solutions across Microsoft 365 Copilot, Copilot Studio and Microsoft Foundry. Decide when to build a custom agent, extend Microsoft 365 Copilot, create a custom model or use a small language model. Set prompt guidelines and a prompt library. Include the elements of an AI Center of Excellence. Build an ROI case, including total cost of ownership, and decide whether to build, buy or extend. Use a model router.

**Design.** Copilot in Dynamics 365 customer experience and service apps, Sales connectors and Contact Center channels. Task, autonomous, and prompt-and-response agents. Copilot Studio topics, including fallback, and when to use classic language understanding versus generative orchestration. Agent flows and prompt actions. Power Platform Well-Architected. Extensibility through custom Foundry models, Microsoft 365 Copilot agents, MCP, computer use, reasoning and voice. AI features in Dynamics 365 finance and supply chain apps, Microsoft 365 Copilot for Sales and for Service, and AI hub in Power Platform.

**Deploy.** Monitor agents and read telemetry. Test agents, validate custom models and design end-to-end tests across Dynamics 365 apps. Design ALM for data, Copilot Studio agents, Foundry Agent Service, custom models and Dynamics 365 AI. Design security, governance, model security, defences against prompt manipulation, responsible AI reviews, data residency checks, access controls and audit trails.
{% endmore %}

## A short study plan

1. Work through the learning path [Architect AI solutions for business productivity](https://learn.microsoft.com/en-us/training/paths/architect-agentic-ai-business-solutions/). It has eleven modules that follow the exam outline, about 11 hours in total.
2. Do two or three of the Copilot Studio labs below, so the design questions make sense in practice.
3. Read the Copilot Studio pages on generative orchestration, system topics, analytics and ALM. Then read the Cloud Adoption Framework pages on AI strategy and the AI Center of Excellence.
4. Take Microsoft's [official practice assessment](https://aiskillsnavigator.microsoft.com/credentials/cert-c8cd10e21263eb422163f34e3672bc61b015f187af7467ca6355b4c3f02cd88a). You need to sign in to AI Skills Navigator.
5. Read the common traps the night before.

Microsoft says its AB-100 course is "not a test-preparation course". It focuses on architecture and trade-offs, not step-by-step setup. That is also what the exam asks about.
{% endnote %}

## Must-know concepts

{% must %}
- **Pick the platform.** Copilot Studio is the SaaS tool for automating business work. Foundry is the development platform with API access. To build on Microsoft 365 Copilot, use its extensibility tools.
- **Three agent types** in the outline: prompt-and-response, task and autonomous.
- **Generative orchestration** is the default for new Copilot Studio agents. It chooses topics, tools and knowledge by their descriptions. MCP and computer use only work with it turned on.
- **Fallback and Escalate.** Fallback fires on an unknown intent, asks the user to rephrase at most twice, then hands over to Escalate.
- **ALM.** Move agents in solutions. Deploy them as managed, except into development. Put values that change between environments in environment variables.
- **AI Center of Excellence.** Start centralized, and move to an advisory model as adoption matures. Secure an executive sponsor first.
{% endmust %}

{% more "Monitoring with Copilot Studio analytics" %}
A session starts as **Unengaged**. Once the user engages, it ends as **Resolved**, **Escalated** or **Abandoned**. An engaged session that times out after 30 minutes counts as abandoned. Customer satisfaction is a score out of 5, where 1 and 2 mean dissatisfied, 3 means neutral, and 4 and 5 mean satisfied.

Monitoring data is kept for up to 360 days. Session details and transcripts are kept for the last 28 days.
{% endmore %}

{% more "ALM details that catch people out" %}
Some settings are **not** part of a solution, so you set them again in each environment. These include Application Insights settings, manual authentication settings, Direct Line and web channel security, deployed channels and sharing.

Power Platform pipelines are built around Managed Environments. From October 2026, admins are told when a pipeline deploys to an unmanaged target, and they have 30 days to turn on Managed Environments before later deployments to that target are blocked. Microsoft recommends a production environment as the pipeline host, and pipelines support approval-based delegated deployments.
{% endmore %}

{% more "Extending agents: MCP, computer use and the model router" %}
**MCP in Copilot Studio** supports MCP tools and resources. When the server changes its tools, Copilot Studio picks up the change on its own.

**Computer use** lets an agent work in apps and websites on a Windows computer when there is no API. Credentials can come from the maker, which suits autonomous agents, or from the end user. A human supervision setting is available.

**Model router** in Foundry sends each prompt to the most suitable model. It has Balanced (the default), Cost and Quality modes, and you can limit it to a subset of models. Its usable context window is only as large as the smallest model it can route to.
{% endmore %}

{% more "Governance and security" %}
Microsoft Purview Data Security Posture Management covers AI apps and agents. It tracks agent activity such as oversharing, data exfiltration and unusual access.

The Power Platform Well-Architected framework has five pillars: Reliability, Security, Operational Excellence, Performance Efficiency and Experience Optimization. Unlike the Azure framework, it has no Cost Optimization pillar.
{% endmore %}

## Common traps

- **Thinking AB-100 alone makes you an Expert.** You also need one Associate certification from Microsoft's list.
- **Adding MCP or computer use to a classic agent.** Both need generative orchestration turned on.
- **Expecting every setting to travel in a solution.** Channels, sharing and Application Insights settings don't. Set them in each environment.
- **Looking for a cost pillar in Power Platform Well-Architected.** It has five pillars, and cost is not one of them.
- **Ignoring preview features.** Microsoft says the exam may include preview features that are in common use.

{% question 1 %}
Your company is setting up Power Platform pipelines to move Copilot Studio agents from development to test and production. Which environment does Microsoft recommend as the pipelines host?

1. The development environment where makers build agents
2. A production environment
3. Each maker's personal developer environment
4. The test environment
---answer---
**Answer: 2.** Microsoft's pipelines guidance says the host environment should be a production environment. Source: [Power Platform pipelines](https://learn.microsoft.com/en-us/power-platform/alm/pipelines).
{% endquestion %}

{% question 2 %}
Your agent calls an internal API. The API address is different in development, test and production. You want the same solution to deploy to all three without editing it after import. What do you use?

1. A separate copy of the agent for each environment.
2. Environment variables in the solution.
3. A topic that asks the user which environment they are in.
4. Unmanaged solutions in every environment.
---answer---
**Answer: 2.** Microsoft's ALM guidance says to use environment variables for settings and secrets that change across environments. It also says to deploy managed solutions except into development, so option 4 is wrong. Source: [Copilot Studio ALM guidance](https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/alm).
{% endquestion %}

{% question 3 %}
A company is starting its first AI projects. Three departments are already trying different tools with no shared rules. Leadership asks you how to set up an AI Center of Excellence. What do you recommend first?

1. Secure an executive sponsor, and start with a centralized CoE.
2. Start with an advisory CoE that lets each department choose its own tools.
3. Wait until the projects are in production, then form a CoE.
4. Hand the CoE to the IT help desk.
---answer---
**Answer: 1.** The Cloud Adoption Framework says the first step is to secure executive sponsorship. Companies at an early stage benefit from a centralized CoE, and move toward an advisory approach as adoption matures. Source: [AI Center of Excellence](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ai/center-of-excellence).
{% endquestion %}

{% question 4 %}
You design a Foundry solution that uses the model router to keep costs down. Testing shows that long contract documents fail, even though one of the models behind the router supports a large context window. What is the most likely cause?

1. The model router only accepts text under 1,000 tokens.
2. The router's usable context window is limited by the smallest model it can route to.
3. Cost mode turns off long-context models.
4. Contract documents need a custom model.
---answer---
**Answer: 2.** Microsoft states that the effective context window of the model router is limited by the smallest underlying model. You can set a model subset to control which models the router uses. Source: [Model router](https://learn.microsoft.com/en-us/azure/foundry/openai/concepts/model-router).
{% endquestion %}

{% question 5 %}
An autonomous Copilot Studio agent must enter supplier invoices into an old desktop finance app every night. The app has no API, and no user is signed in at that time. How should the agent sign in to the app?

1. With the end user's credentials, asked for at run time.
2. With maker-provided credentials.
3. It can't. Computer use needs a user to be present.
4. With a Power Automate desktop flow recorded by each user.
---answer---
**Answer: 2.** Computer use supports maker-provided credentials, which Microsoft describes as the default and suitable for autonomous agents. End-user credentials need someone there to provide them. Source: [Computer use in Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/computer-use).
{% endquestion %}

{% question 6 %}
Your team's MCP server offers tools, resources and a set of prompt templates. You connect it to a Copilot Studio agent. Which of these can the agent use?

1. Tools, resources and prompts.
2. Tools and resources only.
3. Prompts only.
4. Tools only, and only after each one is wrapped in a custom connector.
---answer---
**Answer: 2.** Microsoft says Copilot Studio currently supports MCP tools and resources. Source: [Extend your agent with MCP](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agent-extend-action-mcp).
{% endquestion %}

## Exam day

- **Length:** Microsoft does not state it for AB-100. Its general rule is 100 minutes for expert exams without labs and 120 minutes for exams that may include labs.
- **Pass mark:** 700. Most Microsoft exams have between 40 and 60 questions.
- **Microsoft Learn is open** during the exam, except Q&A and practice assessments. The timer keeps running.
- **Languages:** English and twelve others. If your language isn't offered, you can ask for 30 extra minutes.
- **Booking:** through Pearson VUE. The price depends on your country.
- **Renewal:** free, once a year, through an online assessment on Microsoft Learn.
