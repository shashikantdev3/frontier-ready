<dl class="glossary">
<dt id="letter-a"><span id="a2a">A2A</span></dt>
<dd>Agent2Agent. A protocol that lets one agent talk to another agent, even across different platforms. Compare with MCP, which connects an agent to tools.</dd>
<dt><span id="agent-365">Agent 365</span></dt>
<dd>Microsoft's control plane for agents. It lists every agent in one registry and helps IT observe, govern and secure them. It doesn't build agents. See <a href="/milestone-2/#agent-365-observe-govern-and-secure">Milestone 2</a>.</dd>
<dt><span id="agentic-retrieval">Agentic retrieval</span></dt>
<dd>A search method that plans several queries, runs them across sources and merges the results, instead of one query against one index. It powers Foundry IQ.</dd>
<dt><span id="ai-center-of-excellence">AI Center of Excellence</span></dt>
<dd>A small internal team that guides how a company adopts AI: standards, governance and reuse. An optional module in Milestone 3, and a topic in AB-100.</dd>
<dt><span id="applied-skills">Applied Skills</span></dt>
<dd>Short, lab-based Microsoft credentials. Not required for the badge, but a cheap way to practise.</dd>
<dt id="letter-c"><span id="copilot-studio">Copilot Studio</span></dt>
<dd>Microsoft's low-code tool for building agents, mostly for Microsoft 365.</dd>
<dt><span id="credly">Credly</span></dt>
<dd>The website where the FTE badge is issued and shown. You can share it from there.</dd>
<dt id="letter-f"><span id="fabric-iq">Fabric IQ</span></dt>
<dd>A workload in Microsoft Fabric that gives business data its meaning, through an ontology, data agents and operations agents.</dd>
<dt><span id="foundry-iq">Foundry IQ</span></dt>
<dd>Knowledge bases for agents, built on Azure AI Search. One endpoint searches many sources.</dd>
<dt><span id="frontier-partner-specialization">Frontier Partner specialization</span></dt>
<dd>A Microsoft label for partner companies. It needs, among other things, five people with the FTE badge.</dd>
<dt id="letter-h"><span id="hypervelocity-engineering-hve">Hypervelocity Engineering (HVE)</span></dt>
<dd>Microsoft's framework for building software with AI agents in a disciplined way. Its core is the RPI workflow. See <a href="/milestone-3/">Milestone 3</a>.</dd>
<dt id="letter-k"><span id="knowledge-base">Knowledge base</span></dt>
<dd>In Foundry IQ, a collection of knowledge sources that an agent can search through one endpoint.</dd>
<dt id="letter-l"><span id="levelup">LevelUp</span></dt>
<dd>The training site where the Project Ready courses and assessments run. Sign in through the Partner Skilling Hub.</dd>
<dt id="letter-m"><span id="mcp">MCP</span></dt>
<dd>Model Context Protocol. A standard way to connect an agent to tools and data. Compare with A2A.</dd>
<dt><span id="microsoft-agent-framework">Microsoft Agent Framework</span></dt>
<dd>Microsoft's open-source SDK for building agents in Python and .NET. It replaces Semantic Kernel and AutoGen.</dd>
<dt><span id="microsoft-ai-cloud-partner-program">Microsoft AI Cloud Partner Program</span></dt>
<dd>Microsoft's programme for partner companies. Your company must be enrolled for your work to count.</dd>
<dt><span id="microsoft-foundry">Microsoft Foundry</span></dt>
<dd>Microsoft's platform for building AI apps and agents with code. It used to be called Azure AI Foundry. AI-103 is mostly about it.</dd>
<dt><span id="microsoft-iq">Microsoft IQ</span></dt>
<dd>The umbrella name for Work IQ, Fabric IQ, Foundry IQ and Web IQ: the layers that give Copilot and agents context.</dd>
<dt><span id="microsoft-learn-profile">Microsoft Learn profile</span></dt>
<dd>Your record of exams and certifications. Use a personal Microsoft account as the main sign-in and add your work account to it.</dd>
<dt id="letter-o"><span id="ontology">Ontology</span></dt>
<dd>In Fabric IQ, a model of your business: things like Customer and Order, their properties, relationships and rules, bound to real data.</dd>
<dt id="letter-p"><span id="partner-center">Partner Center</span></dt>
<dd>Microsoft's portal for partner companies. You link your Learn and Skilling Hub profiles here so your work counts for your company.</dd>
<dt><span id="partner-skilling-hub">Partner Skilling Hub</span></dt>
<dd>Microsoft's training site for partners. Sign up with your work email. It is your way in to LevelUp.</dd>
<dt><span id="pearson-vue">Pearson VUE</span></dt>
<dd>The company that runs Microsoft exams, online or at a test centre.</dd>
<dt><span id="project-ready">Project Ready</span></dt>
<dd>The five course assessments in Milestone 2. You need 80% on each.</dd>
<dt id="letter-r"><span id="rag">RAG</span></dt>
<dd>Retrieval-augmented generation. The model looks up relevant documents first, then answers from them.</dd>
<dt><span id="rpi">RPI</span></dt>
<dd>Research, Plan, Implement, Review. The workflow at the centre of Hypervelocity Engineering.</dd>
<dt id="letter-t"><span id="transcript">Transcript</span></dt>
<dd>The page in your Microsoft Learn profile that lists every exam and certification you have passed.</dd>
<dt id="letter-w"><span id="web-iq">Web IQ</span></dt>
<dd>The Microsoft IQ layer that grounds agents in live web results. Added in June 2026.</dd>
<dt><span id="work-iq">Work IQ</span></dt>
<dd>The layer that gives Microsoft 365 Copilot and agents context about how you work: people, meetings, files and chats.</dd>
</dl>
